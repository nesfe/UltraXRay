# Changelog

## 2026.10.01

- Добавлен отдельный профиль Vision EDGE (`fp=edge`) со ссылкой и QR. Обычный Vision Chrome сохранён; оба используют один inbound и одинаковые доступы.
- Добавлена утилита `scripts/add-vision-edge.py` для существующих установок: без изменения конфигурации, ключей, firewall и без перезапуска служб.
- Вывод ссылок поддерживает Edge для старых env-файлов.
- Удалено удаление Docker, Amnezia, Outline, сетей и контейнеров, а также очистка iptables, UFW reset и принудительное завершение процессов на портах.
- Установщик отказывается перезаписывать существующую установку и проверяет конфликты портов до изменения системы, включая публикации Docker.
- Активный UFW получает только три правила UltraXRay. Неактивный UFW не включается; политики и существующие правила сохраняются.
- Для новых установок Hysteria использует UDP 20000 без port hopping и отдельного пользователя `hysteria`.
- Закреплены Xray 26.6.27 и Hysteria 2.12.3. Версии не обновляются произвольно до latest: совместимость Edge проверяется отдельно.
- Старые скрипты восстановления Hysteria сохраняют фактический listen вместо принудительного включения широкого диапазона.
- Добавлены проверки профилей и сценариев отказа установщика, CI и документация миграции.

Существующие серверы не обновляются и не мигрируют при публикации релиза. Для Edge достаточно создать и импортировать дополнительную клиентскую ссылку.
