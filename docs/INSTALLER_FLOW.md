# Установщик 2026.10.01

`scripts/install-ultraxray.sh` создаёт новую установку. Он не выполняет очистку или автоматическую переустановку.

1. Проверяет root, отсутствие конфигурации/бинарников/служб Xray и Hysteria, свободные TCP 443/8443 и UDP 20000. Также проверяет публикации Docker, включая диапазоны портов. Ошибка проверки останавливает установку.
2. Спрашивает REALITY SNI и пароль Hysteria. Нормализует URL до hostname.
3. Устанавливает зависимости; `NEEDRESTART_MODE=l` не просит автоматически перезапускать остальные службы.
4. Проверяет TLS 1.3 целевого SNI с таймаутом и проверкой сертификата.
5. Через официальные установщики устанавливает закреплённые Xray 26.6.27 и Hysteria 2.12.3. Hysteria работает от своего пользователя, не root.
6. Создаёт независимые ключи для XHTTP и Vision, пару VLESS Encryption для XHTTP. Проверяет Xray-конфигурацию через `run -test`.
7. Создаёт сертификат и конфигурацию Hysteria с `listen: :20000`. Широкие UDP-перенаправления не создаются.
8. В активный UFW добавляет три разрешающих правила. Неактивный UFW оставляет неактивным. Не меняет политики, правила SSH, Docker или Amnezia.
9. Запускает только созданные службы Xray/Hysteria и проверяет порты.
10. Сохраняет ссылки, QR-коды и env-файл. Vision Edge отличается от обычного Vision только `fp=edge` и названием; нового inbound нет.

Если установка остановилась после записи файлов, повторный запуск откажется их перезаписывать. Автоматического отката пакетов или частично созданной установки нет: нужно изучить причину ошибки.

Для уже работающего Vision используйте `python3 scripts/add-vision-edge.py`. Эта команда не запускает установщик, не меняет конфигурацию и не перезапускает службы.
